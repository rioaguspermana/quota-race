# Ethics & allowed use

## Allowed

- Staging / local / APIs **you own** or have **explicit written permission** to test  
- Demonstrating intentional racey demos shipped with this project  
- Teaching concurrency / TOCTOU with consenting systems  

## Not allowed / discouraged

- Running against third-party production without authorization  
- Using as a DoS / abuse tool  
- Marketing claims that imply illegal access is OK  

## Product copy requirements

Every user-facing surface (README, `--help`) should include a short **own-API only** notice.

## Security research

If users adapt this for bounty programs, they must follow that program’s rules. This project does not grant authorization.
